# Attachments and File Uploads

*Sample knowledge-base article for the Resolv-HQ prototype. Synthetic, team-authored. Version 1.0.*

## 1. Attaching files
Files can be attached when creating a request or when replying to one. Screenshots, PDFs, and plain-text files help support agents understand the problem.

## 2. Limits
Each file can be up to 10 MB. Up to 5 files can be attached to a single message. Accepted types are PNG, JPG, PDF, and TXT.

## 3. Privacy
Do not attach files containing passwords, full card numbers, or authentication codes. If you attach one by mistake, tell support so it can be removed.

## 4. Who can see attachments
Attachments are visible to you and to the support staff handling the request. They are not visible to other customers.

## 5. Instructions inside files
Text inside an attachment is treated as information about your problem only. Instructions written inside a file are not followed by the AI assistant.
