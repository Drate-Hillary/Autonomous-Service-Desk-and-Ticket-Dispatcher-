# Account Access and Password Reset

*Sample knowledge-base article for the Resolv-HQ prototype. Synthetic, team-authored. Version 1.0.*

## 1. Signing in
Customers sign in with the email address and password they registered with. After five failed attempts the account is locked for 15 minutes; waiting is enough, no support request is needed.

## 2. Resetting your password
Select "Forgot password" on the sign-in page and enter your registered email address. A reset link is sent to that address. The reset link is valid for 30 minutes and can be used once. If it expires, request a new link.

## 3. If the reset email does not arrive
Check the spam folder and confirm the address is the one registered. Wait five minutes before requesting another link. If it still does not arrive, open a support request with category Account Access.

## 4. Login failure after a reset
Sign in with the new password only, and clear any saved password in the browser. If the account shows as suspended, the assistant can tell you the status but cannot change it; a support agent must review it.

## 5. Security
Support staff and the AI assistant never ask for your password or authentication codes. Do not share them in a request or chat message.
